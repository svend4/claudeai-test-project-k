1. ОБЩИЙ ОБЗОР CLAUDE CODE
================================================================================

Claude Code — официальный CLI-инструмент (интерфейс командной строки) от
компании Anthropic для работы с моделями Claude. Запускается напрямую в терминале
и позволяет выполнять сложные задачи программирования в интерактивном режиме.

  Текущая модель: Claude Sonnet 4.6 (claude-sonnet-4-6)
  Актуальные модели семейства Claude 4.5/4.6:
    - Claude Opus 4.6:   claude-opus-4-6         (самая мощная)
    - Claude Sonnet 4.6: claude-sonnet-4-6        (баланс мощности/скорости)
    - Claude Haiku 4.5:  claude-haiku-4-5-20251001 (быстрая и экономичная)

  Ключевые особенности:
    - Полный доступ к файловой системе проекта
    - Выполнение команд в терминале
    - Работа с Git и GitHub
    - Поиск по коду и файлам
    - Интерактивный диалог с сохранением контекста
    - Параллельное выполнение инструментов

2. ИНСТРУМЕНТЫ (TOOLS) — ПОЛНЫЙ СПИСОК И ОПИСАНИЕ
================================================================================

Инструменты — это основные «руки» Claude Code, позволяющие взаимодействовать
с системой. Каждый инструмент специализирован под конкретный тип задач.

------------------------------------------------------------------------
2.1 ИНСТРУМЕНТЫ РАБОТЫ С ФАЙЛАМИ
------------------------------------------------------------------------

  [Read] — Чтение файлов
    Описание:  Читает файлы из файловой системы. Поддерживает:
                - Текстовые файлы (любые форматы)
                - Изображения (PNG, JPG и другие — мультимодально!)
                - PDF-файлы (до 20 страниц за запрос)
                - Jupyter Notebooks (.ipynb)
    Параметры: file_path, limit (лимит строк), offset (смещение), pages (PDF)
    Пример:    Читать файл с 100-й по 200-ю строку

  [Write] — Создание/перезапись файлов
    Описание:  Полностью создаёт или перезаписывает файл.
                ВАЖНО: Предпочтительнее использовать Edit для правок.
                Подходит для создания новых файлов с нуля.
    Параметры: file_path, content
    Пример:    Создать новый конфигурационный файл

  [Edit] — Точечное редактирование файлов
    Описание:  Заменяет конкретные строки/блоки кода в файле.
                Умнее Write — отправляет только дифф (изменения).
                Поддерживает replace_all для массовой замены.
    Параметры: file_path, old_string, new_string, replace_all
    Пример:    Переименовать функцию во всём файле

  [NotebookEdit] — Редактирование Jupyter Notebook
    Описание:  Редактирует конкретные ячейки (.ipynb файлов).
                Режимы: replace (замена), insert (вставка), delete (удаление)
    Параметры: notebook_path, new_source, cell_id, cell_type, edit_mode
    Пример:    Вставить новую ячейку с кодом в ноутбук

------------------------------------------------------------------------
2.2 ИНСТРУМЕНТЫ ПОИСКА
------------------------------------------------------------------------

  [Glob] — Поиск файлов по шаблону
    Описание:  Быстрый поиск файлов по glob-паттернам.
                Результаты отсортированы по времени изменения.
                Намного быстрее команды `find`.
    Параметры: pattern, path
    Примеры:   "**/*.py" — все Python-файлы рекурсивно
               "src/**/*.tsx" — все TSX в папке src

  [Grep] — Поиск по содержимому файлов
    Описание:  Мощный поиск по содержимому на основе ripgrep.
                Поддерживает полный синтаксис регулярных выражений.
                Режимы вывода: content, files_with_matches, count
    Параметры: pattern, path, glob, type, output_mode, -i, -A, -B, -C
    Примеры:   Найти все функции с именем "auth"
               Найти все TODO-комментарии в проекте

------------------------------------------------------------------------
2.3 ИНСТРУМЕНТЫ ВЫПОЛНЕНИЯ
------------------------------------------------------------------------

  [Bash] — Выполнение команд в терминале
    Описание:  Запускает произвольные bash-команды.
                Поддерживает фоновое выполнение (run_in_background).
                Таймаут до 10 минут.
                Рабочая директория сохраняется между вызовами.
    Параметры: command, description, run_in_background, timeout
    Примеры:   git push, npm install, pytest, docker build

------------------------------------------------------------------------
2.4 ВЕБ-ИНСТРУМЕНТЫ
------------------------------------------------------------------------

  [WebFetch] — Получение содержимого URL
    Описание:  Загружает веб-страницу и обрабатывает её содержимое.
                Конвертирует HTML в markdown.
                Кэш 15 минут для повторных запросов.
                HTTP автоматически обновляется до HTTPS.
    Параметры: url, prompt
    Пример:    Прочитать документацию с официального сайта

  [WebSearch] — Поиск в интернете
    Описание:  Выполняет поиск в интернете для получения актуальной
                информации (важно — знания Claude ограничены августом 2025).
                Поддерживает фильтрацию по доменам.
    Параметры: query, allowed_domains, blocked_domains
    Пример:    Найти последние новости о Python 3.14

------------------------------------------------------------------------
2.5 ИНСТРУМЕНТЫ УПРАВЛЕНИЯ ЗАДАЧАМИ
------------------------------------------------------------------------

  [TodoWrite] — Список задач
    Описание:  Создаёт и управляет структурированным списком задач.
                Статусы: pending (ожидание), in_progress (в работе),
                          completed (завершено).
                Показывает пользователю прогресс выполнения.
    Параметры: todos (массив объектов с полями content, status, activeForm)
    Пример:    Отслеживать шаги при рефакторинге большого модуля

------------------------------------------------------------------------
2.6 ИНСТРУМЕНТЫ ВЗАИМОДЕЙСТВИЯ
------------------------------------------------------------------------

  [AskUserQuestion] — Интерактивные вопросы
    Описание:  Задаёт пользователю структурированные вопросы с вариантами
                ответов. Поддерживает одиночный и множественный выбор.
                Поддерживает предпросмотр markdown для сравнения вариантов.
    Параметры: questions (массив вопросов с options)
    Пример:    Выбор между несколькими архитектурными подходами

  [Agent] — Запуск специализированных агентов
    Описание:  Запускает подпроцессы-агенты для сложных задач.
                Может работать в фоне (run_in_background).
                Поддерживает изоляцию через git worktree.
                Агенты могут возобновляться (resume).
    Параметры: subagent_type, prompt, description, isolation, max_turns

  [Skill] — Вызов пользовательских навыков
    Описание:  Вызывает специализированные навыки (skills).
                Аналог slash-команд для пользователя.
    Параметры: skill, args

  [ExitPlanMode] — Завершение режима планирования
    Описание:  Используется в режиме планирования для передачи плана
                пользователю на утверждение перед реализацией.
    Параметры: allowedPrompts

================================================================================
3. НАВЫКИ (SKILLS) — ПОЛЬЗОВАТЕЛЬСКИЕ КОМАНДЫ
================================================================================

Skills — это расширяемые пользовательские команды, которые добавляют Claude Code
специализированные возможности. Вызываются через слэш-команды (/skill-name).

------------------------------------------------------------------------
3.1 ВСТРОЕННЫЕ НАВЫКИ (обнаружены в текущей среде)
------------------------------------------------------------------------

  [simplify] — Упрощение и оптимизация кода
    Описание:  Анализирует изменённый код на предмет:
                - Возможностей повторного использования (DRY-принцип)
                - Качества кода (читаемость, стиль)
                - Эффективности (производительность, оптимизация)
                Автоматически исправляет найденные проблемы.
    Использование: /simplify
    Когда применять: После написания нового кода или рефакторинга

  [session-start-hook] — Настройка хуков запуска сессии
    Описание:  Специализированный навык для настройки репозитория
                под работу с Claude Code в веб-режиме.
                Создаёт SessionStart хук для автоматического запуска
                тестов и линтеров при каждой новой сессии.
    Использование: /session-start-hook
    Когда применять: При первоначальной настройке проекта для веб-работы

------------------------------------------------------------------------
3.2 КАК СОЗДАЮТСЯ ПОЛЬЗОВАТЕЛЬСКИЕ НАВЫКИ
------------------------------------------------------------------------

  Навыки могут быть настроены пользователем через:
    - Конфигурационные файлы Claude Code
    - Файл CLAUDE.md (инструкции для агента)
    - Настройки проекта (.claude/ директория)

  Структура навыка:
    - Имя (вызывается через /имя-навыка)
    - Описание и контекст применения
    - Набор инструментов, которые доступны навыку
    - Логика выполнения (prompt-шаблон)

================================================================================
4. ХУКИ (HOOKS) — АВТОМАТИЗАЦИЯ СОБЫТИЙ
================================================================================

Хуки — это shell-команды, которые автоматически выполняются в ответ
на определённые события в Claude Code.

------------------------------------------------------------------------
4.1 ТИПЫ ХУКОВ
------------------------------------------------------------------------

  [SessionStart] — Хук запуска сессии
    Описание:  Выполняется при старте каждой новой сессии Claude Code.
    Применение: Запуск тестов, проверка линтеров, инициализация окружения,
                 проверка зависимостей, установка переменных среды.
    Пример:    Автоматически запустить `npm test` или `python -m pytest`
                при начале работы над проектом.

  [Tool call hooks] — Хуки вызова инструментов
    Описание:  Выполняются до или после вызова конкретных инструментов.
    Применение: Логирование, аудит безопасности, дополнительная валидация.
    Пример:    Перехватить вызов Bash для проверки безопасности команды.

------------------------------------------------------------------------
4.2 КАК НАСТРАИВАЮТСЯ ХУКИ
------------------------------------------------------------------------

  Хуки настраиваются через:
    - Настройки Claude Code (settings)
    - Файл конфигурации проекта
    - Команду /session-start-hook для автоматической настройки

  ВАЖНО: Обратная связь от хуков воспринимается Claude как сообщения
          от пользователя, что позволяет хукам влиять на поведение агента.

================================================================================
5. АГЕНТЫ (AGENTS) — СПЕЦИАЛИЗИРОВАННЫЕ ПОДПРОЦЕССЫ
================================================================================

Агенты — это специализированные подпроцессы, которые могут автономно
выполнять сложные задачи. Запускаются через инструмент [Agent].

------------------------------------------------------------------------
5.1 ТИПЫ АГЕНТОВ
------------------------------------------------------------------------

  [general-purpose] — Агент общего назначения
    Инструменты: Все доступные инструменты (*)
    Применение:  Комплексные исследования кодовой базы,
                  поиск файлов по ключевым словам (когда не уверен в результате),
                  многошаговые задачи.
    Особенность: Наиболее универсальный — используйте когда другие не подходят.

  [statusline-setup] — Настройка строки статуса
    Инструменты: Read, Edit
    Применение:  Настройка статусной строки Claude Code.
                  Конфигурирование отображения информации.

  [Explore] — Быстрое исследование кодовой базы
    Инструменты: Все, кроме Agent, ExitPlanMode, Edit, Write, NotebookEdit
    Применение:  Поиск файлов по паттернам (src/components/**/*.tsx),
                  поиск по ключевым словам кода,
                  ответы на вопросы об архитектуре.
    Уровни:      quick (базовый), medium (умеренный), very thorough (глубокий)

  [Plan] — Агент-архитектор
    Инструменты: Все, кроме Agent, ExitPlanMode, Edit, Write, NotebookEdit
    Применение:  Проектирование стратегии реализации,
                  создание пошаговых планов,
                  анализ архитектурных компромиссов.
    Результат:   Пошаговый план с указанием критических файлов.

  [claude-code-guide] — Гид по Claude Code
    Инструменты: Glob, Grep, Read, WebFetch, WebSearch
    Применение:  Вопросы о Claude Code CLI (функции, хуки, slash-команды,
                  MCP-серверы, настройки, интеграции с IDE),
                  Claude Agent SDK (создание кастомных агентов),
                  Claude API (использование, tool use, Anthropic SDK).
    Особенность: Можно ВОЗОБНОВИТЬ через параметр resume (экономия ресурсов).

------------------------------------------------------------------------
5.2 ОСОБЕННОСТИ АГЕНТОВ
------------------------------------------------------------------------

  - Изоляция через git worktree (параметр isolation: "worktree")
    Агент работает в изолированной копии репозитория. Worktree
    автоматически удаляется если изменений нет.

  - Фоновое выполнение (run_in_background: true)
    Агент работает параллельно с основным процессом.
    Уведомление приходит автоматически по завершении.

  - Возобновление (resume: "<agent_id>")
    Агент продолжает с полным сохранённым контекстом предыдущей сессии.

  - Параллельный запуск
    Несколько агентов можно запускать одновременно в одном сообщении,
    что значительно ускоряет выполнение независимых задач.

6. MCP-СЕРВЕРЫ — РАСШИРЕНИЯ ЧЕРЕЗ ПРОТОКОЛ КОНТЕКСТА
================================================================================

MCP (Model Context Protocol) — открытый протокол Anthropic для подключения
внешних инструментов и сервисов к Claude Code.

------------------------------------------------------------------------
6.1 ЧТО ТАКОЕ MCP
------------------------------------------------------------------------

  MCP позволяет:
    - Подключать внешние базы данных (PostgreSQL, MongoDB и др.)
    - Интегрировать корпоративные инструменты (Jira, Confluence и др.)
    - Добавлять специализированные API (Stripe, Twilio и др.)
    - Расширять возможности веб-поиска и работы с данными

------------------------------------------------------------------------
6.2 ТИПЫ MCP-РЕСУРСОВ
------------------------------------------------------------------------

  Инструменты (Tools):
    Пользовательские инструменты, которые Claude может вызывать.
    Пример: custom_db_query, send_slack_message, deploy_to_staging

  Ресурсы (Resources):
    Данные, которые Claude может читать.
    Пример: файлы конфигурации, схемы баз данных, документация API

  Промпты (Prompts):
    Переиспользуемые шаблоны взаимодействия.

------------------------------------------------------------------------
6.3 НАСТРОЙКА MCP
------------------------------------------------------------------------

  MCP-серверы настраиваются через конфигурацию Claude Code.
  Предпочтение отдаётся MCP-инструментам перед встроенными
  (например, MCP WebFetch предпочтительнее встроенного).

7. SLASH-КОМАНДЫ — ВСТРОЕННЫЕ КОМАНДЫ CLI
================================================================================

Slash-команды — встроенные команды CLI и пользовательские навыки,
вызываемые через /имя-команды.

------------------------------------------------------------------------
7.1 ВСТРОЕННЫЕ SLASH-КОМАНДЫ
------------------------------------------------------------------------

  /help           — Получить справку по использованию Claude Code
  /clear          — Очистить историю текущего разговора
  /fast           — Переключить режим быстрого вывода (Fast Mode)
  /commit         — Создать git-коммит (через навык)
  /review-pr      — Проверить pull request (через навык)

------------------------------------------------------------------------
7.2 ПОЛЬЗОВАТЕЛЬСКИЕ SLASH-КОМАНДЫ (НАВЫКИ)
------------------------------------------------------------------------

  /simplify       — Упрощение и оптимизация изменённого кода
  /session-start-hook — Настройка хука запуска сессии
  /pdf            — Работа с PDF файлами (если навык подключён)

  ВАЖНО: Slash-команды, настроенные пользователем, называются "навыками" (skills).
          Не путать со встроенными CLI-командами!

================================================================================
8. РЕЖИМЫ РАЗРЕШЕНИЙ — УРОВНИ ДОСТУПА
================================================================================

Claude Code поддерживает несколько режимов разрешений для управления
тем, что агент может делать без подтверждения пользователя.

------------------------------------------------------------------------
8.1 УРОВНИ РАЗРЕШЕНИЙ
------------------------------------------------------------------------

  Автоматические разрешения (без подтверждения):
    - Чтение файлов (Read, Glob, Grep)
    - Локальные обратимые действия (Edit, Write)
    - Безвредные bash-команды (ls, cat и подобные)

  Требуют подтверждения пользователя:
    - Деструктивные операции (rm, git reset --hard)
    - git push, создание PR и Issues
    - Отправка сообщений (Slack, email и др.)
    - Изменения CI/CD пайплайнов
    - Модификация общей инфраструктуры

  НИКОГДА не выполняются без явного запроса:
    - git push --force на main/master
    - Пропуск хуков (--no-verify)
    - Форс-пуш

------------------------------------------------------------------------
8.2 DURABLE ИНСТРУКЦИИ
------------------------------------------------------------------------

  Файл CLAUDE.md:
    Постоянные инструкции для агента на уровне проекта.
    Определяет что разрешено/запрещено для данного репозитория.
    Располагается в корне проекта.

================================================================================
9. МУЛЬТИМОДАЛЬНЫЕ ВОЗМОЖНОСТИ
================================================================================

Claude Code — мультимодальный агент, способный работать с разными типами данных:

------------------------------------------------------------------------
9.1 ПОДДЕРЖИВАЕМЫЕ ФОРМАТЫ
------------------------------------------------------------------------

  Изображения:
    Форматы:   PNG, JPG и другие распространённые форматы
    Как читать: Инструмент [Read] с путём к изображению
    Применение: Анализ скриншотов, UI-макетов, диаграмм,
                 чтение текста с изображений, анализ графиков

  PDF-файлы:
    Формат:    .pdf
    Как читать: [Read] с параметром pages (например, "1-5")
    Ограничение: Максимум 20 страниц за один запрос
    Большие PDF: ОБЯЗАТЕЛЬНО указывать pages для крупных файлов

  Jupyter Notebooks:
    Формат:    .ipynb
    Как читать: [Read] — возвращает все ячейки с выводом
    Как редактировать: [NotebookEdit] — изменение отдельных ячеек
    Включает: код, текст, визуализации

  Текстовые файлы:
    Поддержка: Любой текстовый формат
    Чтение с лимитом: параметры offset и limit для больших файлов

10. ИНТЕГРАЦИИ С IDE
================================================================================

Claude Code интегрируется с популярными редакторами кода:

------------------------------------------------------------------------
10.1 ПОДДЕРЖИВАЕМЫЕ IDE
------------------------------------------------------------------------

  VS Code:
    - Расширение Claude Code для VS Code
    - Статусная строка в редакторе
    - Горячие клавиши для взаимодействия
    - Просмотр изменений прямо в редакторе

  JetBrains IDE:
    - IntelliJ IDEA, PyCharm, WebStorm и другие
    - Плагин Claude Code для семейства JetBrains
    - Аналогичная функциональность

10.2 ГОРЯЧИЕ КЛАВИШИ
------------------------------------------------------------------------

  Доступны через интеграцию с IDE — позволяют быстро:
    - Открыть диалог с Claude Code
    - Отправить выделенный код на анализ
    - Применить предложенные изменения

================================================================================
11. ПРОЧИЕ ВОЗМОЖНОСТИ
================================================================================

------------------------------------------------------------------------
11.1 УПРАВЛЕНИЕ GIT
------------------------------------------------------------------------

  Полная поддержка Git-операций:
    - git status, log, diff, add, commit, push, pull
    - Работа с ветками (branch, checkout, merge)
    - Создание Pull Requests через GitHub CLI (gh)
    - Управление Issues на GitHub
    - Работа с GitHub Actions (просмотр статуса runs)

  Правила безопасной работы с Git:
    - Предпочтение новых коммитов вместо amend
    - Никогда не пропускать хуки без явного запроса
    - Предупреждение при force-push на main/master
    - Staging конкретных файлов (не git add -A)

------------------------------------------------------------------------
11.2 FAST MODE (БЫСТРЫЙ РЕЖИМ)
------------------------------------------------------------------------

  Описание:  Ускоренный режим вывода Claude Code.
              Использует ту же модель (Claude Opus 4.6), но с быстрым выводом.
              НЕ переключается на другую модель.
  Включение: Команда /fast
  Применение: Когда нужны быстрые ответы на простые задачи.

------------------------------------------------------------------------
11.3 УПРАВЛЕНИЕ КОНТЕКСТОМ
------------------------------------------------------------------------

  Автоматическое сжатие:
    При приближении к лимиту контекста система автоматически
    сжимает предыдущие сообщения. Разговор не ограничен
    размером контекстного окна.

  Сохранение контекста агентов:
    Агенты, запущенные через [Agent] с параметром resume,
    сохраняют полный контекст предыдущей сессии.

------------------------------------------------------------------------
11.4 ПЛАНИРОВАНИЕ (PLAN MODE)
------------------------------------------------------------------------

  Режим планирования:
    Claude может работать в режиме планировщика-архитектора:
    1. Анализирует задачу
    2. Использует AskUserQuestion для уточнений
    3. Составляет план реализации
    4. Вызывает ExitPlanMode для передачи плана на утверждение
    5. Пользователь одобряет — реализация начинается

------------------------------------------------------------------------
11.5 БЕЗОПАСНОСТЬ КОДА
------------------------------------------------------------------------

  Claude Code активно проверяет код на уязвимости:
    - SQL-инъекции
    - XSS (межсайтовый скриптинг)
    - Command Injection (внедрение команд)
    - Другие уязвимости OWASP Top 10

  Анализ вредоносного ПО:
    При чтении каждого файла проверяется возможность того,
    что код является вредоносным (malware).
    Анализ предоставляется, улучшение — нет.

  Ограничения безопасности:
    - Помощь с авторизованным тестированием безопасности: ДА
    - CTF-задания и образовательный контекст: ДА
    - Деструктивные техники и DoS-атаки: НЕТ
    - Уклонение от обнаружения для злоумышленников: НЕТ

------------------------------------------------------------------------
11.6 ПАРАЛЛЕЛЬНОЕ ВЫПОЛНЕНИЕ
------------------------------------------------------------------------

  Claude Code может параллельно:
    - Читать несколько файлов одновременно
    - Запускать несколько поисков параллельно
    - Выполнять несколько команд bash одновременно
    - Запускать нескольких агентов параллельно

  Это значительно ускоряет выполнение сложных задач.

ЗАКЛЮЧЕНИЕ
================================================================================

Claude Code — это мощная и многофункциональная система для разработки
программного обеспечения с поддержкой ИИ. Ключевые сильные стороны:

  1. ГЛУБОКАЯ ИНТЕГРАЦИЯ с файловой системой и git
  2. РАСШИРЯЕМОСТЬ через Skills, Hooks и MCP-серверы
  3. ПАРАЛЛЕЛЬНОСТЬ выполнения инструментов и агентов
  4. МУЛЬТИМОДАЛЬНОСТЬ — работа с текстом, изображениями, PDF, ноутбуками
  5. БЕЗОПАСНОСТЬ — встроенные проверки безопасности кода
  6. ИНТЕРАКТИВНОСТЬ — вопросы к пользователю, режим планирования
  7. КОНТЕКСТ — сохранение контекста между сессиями

  Версия платформы: Claude Code с Claude Sonnet 4.6
  Дата отчёта: 28 февраля 2026 г.
